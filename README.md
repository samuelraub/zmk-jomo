## Leader sequences

Tap the outer right thumb, then type the sequence.

| Sequence | Action                             |
| -------- | ---------------------------------- |
| `C I`    | Clock in (Trackit picker, F17)     |
| `C O`    | Clock out (Trackit, F18)           |
